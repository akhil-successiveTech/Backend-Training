## Install and Set Up Postman
-> Open a terminal
-> Add the postman repository: sudo sh -c 'echo "deb https://dl.pstmn.io/download/latest/linux64" > /etc/apt/sources.list.d/postman.list'
-> Import the Postman GPG Key: sudo apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv-keys 379CE192D401AB61
-> Update the package list: sudo apt-get update
-> Install Postman: sudo apt-get install postman
