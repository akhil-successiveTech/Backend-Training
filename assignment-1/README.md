# Backend-Training
## NodeJS
Node.js is an open-source, cross-platform JavaScript runtime environment that allows you to run JavaScript code outside of a browser. It is commonly used to build scalable network applications and backend services.

Official website: [https://nodejs.org](https://nodejs.org)

## How to install NodeJS
1. Update Package Lists:  sudo apt update
2. Install Node.js: sudo apt install curl , curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
3. Install nodeJS and npm: sudo apt install nodejs
4. Verify installation: node -v
