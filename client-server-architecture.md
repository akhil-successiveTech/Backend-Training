# Express.js
-> A fast and minimalist Node.js web framework.
-> Helps build APIs and web servers easily using routes and middleware.

## Other NodeJS Frameworks
-> Koa – modern, async-based, minimal.
-> NestJS – Angular-style, TypeScript-based, scalable.
-> Hapi – plugin-based, configuration-driven.
-> Sails – MVC-style, good for real-time apps.
-> Fastify – very fast, schema-based.

## Why use Frameworks
-> Saves time and reduces boilerplate.
-> Encourages clean, scalable architecture.
-> Provides built-in routing, middleware, error handling, etc.

## Rest API's
-> Use HTTP methods to manage data:
    GET (read), POST (create), PUT (update), DELETE (delete)
-> Based on stateless requests.
-> Returns JSON and HTTP status codes (200, 404, 500, etc.).
