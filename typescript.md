# TypeScript

TypeScript is a **typed superset of JavaScript** that compiles to plain JavaScript. It helps catch errors early and supports better tooling for large codebases.

---

## Why Use TypeScript?

- Detects errors during development
- Adds type safety
- Supports latest JavaScript features
- Enhances code readability and maintainability

---

## Basic Types in TypeScript

- number
- string
- boolean
- any
- unknown
- null & undefined
- array
- object
